# Zecpath AI Hiring Platform

## Overview

Zecpath is an AI-powered autonomous hiring platform designed to automate the end-to-end recruitment lifecycle including:

- AI ATS Resume Screening
- AI Voice Screening
- AI HR Interviews
- AI Technical Interviews
- Behavioral Analysis
- AI Decision & Scoring Engine

This repository contains the foundational AI environment and scalable modular architecture for all AI systems used in Zecpath.

---

# Tech Stack

- Python 3.11+
- FastAPI
- Pytest
- Loguru
- Scikit-learn
- NLP / AI Modules
- GitHub Version Control
